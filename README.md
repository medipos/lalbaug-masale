## 📌 महत्त्वाची माहिती: 'Images' का दिसत नव्हत्या व आता कशा दिसतील? (Why images were missing & how it is fixed)
1. **HTML फाईलचे स्वरूप**: जेव्हा तुम्ही फक्त एकटी `index.html` डाऊनलोड किंवा WhatsApp वर शेअर करता, तेव्हा त्यात स्थानिक फोटो साठवलेले नसतात. फोटो `images/` या स्वतंत्र फोल्डरमध्ये असतात.
2. **काय बदल केला आहे (Permanent Fix)**:
   - **पॅक १ (ऑफलाईन/लोकल)**: या पॅकेजमध्ये सर्व अस्सल HD फोटो `images/` फोल्डरमध्ये समाविष्ट आहेत. त्यामुळे हे फोल्डर एक्स्ट्रॅक्ट करून चालवल्यास सर्व फोटो उत्तम दिसतात.
   - **पॅक २ (क्लाऊड बॅकअप Fallback)**: जर कोणी चुकून फक्त `index.html` फाईल उघडली, तरीही कोडमध्ये ऑटोमॅटिक क्लाऊड CDN व SVG Fallback जोडला आहे; त्यामुळे फोटो **कधीही फुटणार (Broken [x]) नाहीत**!
   - **पॅक ३ (GitHub Pages सुसंगत)**: सर्व लिंक्स व इमेज पाथ्स `./images/...` रिलेटिव्ह केले आहेत, जेणेकरून गिटहब पेजेसवर कोणतीही अडचण येत नाही.

## 🚀 पर्याय १: GitHub Pages वर ५ मिनिटांत Live करा (Free Hosting)

### पायरी १: GitHub वर नवीन Repository बनवा
1. [github.com](https://github.com) वर जा आणि लॉगिन करा.
2. हिरव्या रंगाच्या **"New"** बटणावर क्लिक करा (नवीन Repository तयार करण्यासाठी).
3. Repository चे नाव द्या: उदा. `lalbaug-masale`.
4. **Public** पर्याय निवडा.
5. **"Create repository"** बटणावर क्लिक करा.

### पायरी २: फाईल्स अपलोड करा
1. तयार झालेल्या पानावर **"uploading an existing file"** या लिंकवर क्लिक करा.
2. या झिप फाईलमधील (`Lalbaug_Masale_Live_Package.zip`) सर्व फाईल्स अनझिप करून त्यातील खालील फाईल्स ड्रॅग-अँड-ड्रॉप (Drag & Drop) करा:
   - `index.html`
   - `customer.html`
   - `admin.html`
   - `.nojekyll`
   - `404.html`
   - `images/` फोल्डर (आतील सर्व फोटोंसह)
3. खाली **"Commit changes"** बटणावर क्लिक करा.

### पायरी ३: GitHub Pages चालू करा
1. तुमच्या Repository च्या वरच्या मेनूमधील **"Settings"** टॅबवर क्लिक करा.
2. डाव्या बाजूच्या मेनूमधून **"Pages"** वर क्लिक करा.
3. "Branch" खाली **"None"** ऐवजी **"main"** (किंवा `master`) निवडा, फोल्डर `/ (root)` ठेवा आणि **"Save"** दाबा.
4. १ ते २ मिनिटांत तुम्हाला तुमची लाईव्ह लिंक मिळेल:
   - **ग्राहक स्टोअर (Customer Panel)**: `https://<तुमचे-युझरनेम>.github.io/lalbaug-masale/`
   - **व्यवस्थापक पोर्टल (Admin Panel)**: `https://<तुमचे-युझरनेम>.github.io/lalbaug-masale/admin.html`

## 🔥 पर्याय २: Firebase Hosting व Backend सह Live करा

### पायरी १: Firebase CLI इन्स्टॉल व लॉगिन
```bash
npm install -g firebase-tools
firebase login
```

### पायरी २: प्रोजेक्ट सुरू करा (जर केलेला नसेल)
```bash
firebase init hosting
```
- विचारल्यावर "Use an existing project" निवडा.
- Public directory विचारल्यास `.` टाईप करा.
- Configure as single-page app विचारल्यास `N` टाईप करा.

### पायरी ३: थेट Deploy करा
```bash
firebase deploy
```
तुमची लाईव्ह वेबसाईट लगेच सुरू होईल:
- **ग्राहक पॅनेल**: `https://<your-project-id>.web.app/`
- **अॅडमीन पॅनेल**: `https://<your-project-id>.web.app/admin`
